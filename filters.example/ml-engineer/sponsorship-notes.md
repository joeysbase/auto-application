# Checking visa sponsorship

1. If the posting says it sponsors, or says it can't ("unable to sponsor", "must be authorized to work
   without sponsorship"), use that — no lookup needed.
2. If it says nothing, search for the company's H-1B history (e.g. "<company> H-1B sponsorship"):
   a company that filed H-1B petitions for similar roles in recent years likely still sponsors.
3. If you can't tell, don't treat it as a deal-breaker — mention it in the reason.
