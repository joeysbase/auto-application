# 2026-10-05 — Step 3 A7.1: the browser-agent applier starts jobs

## What
Milestone A7.1 of [the browser-agent applier](../step3-agent.md): the tools, the guards, and **starting a job** (a dry run that fills step 1 only).

- **`agent` applier:** Claude **Opus 5.5** through the **Claude Agent SDK on your Claude Code login**, verified to work with no API key. It runs in a loop with **only our tools**:
  - browser tools: `snapshot` (every field, button and message with refs, in every frame), `click`, `type`, `select`, `check`, `upload_cv`, `press`, `scroll`, `wait`, `screenshot`;
  - data tools: `answer_for` (your earlier answers → profile → answers.yaml → Claude; sensitive questions only from answers.yaml; drafts for free text), `ask_user` (→ Needs input), `done`.
- **Guards in the tools:**
  - no submit outside `s`;
  - no Next in a dry run (Next sends the step to the site);
  - the browser stays on the job's site and the ATS sites it uses (a blocked link goes back);
  - sensitive fields take only your saved answer;
  - passwords never shown or logged.
- **A last check:** a required field left empty becomes a question for you.
- **A time limit** per run (10 min starting a job, 20 min fill / submit; no token budget). Tokens and minutes are shown in the reason.
- **A log per run:** `data/logs/agent/<application>-<time>.jsonl`.
- **The default applier** (your call): `greenhouse → agent → simplify → manual` on Greenhouse, `agent → simplify → manual` everywhere else, LinkedIn Easy Apply unchanged. No `config/apply.yaml` is needed. `simplify_auto` left the defaults (name it in `config/apply.yaml` to use it).
- **Fill only / submit and accounts come in A7.3.** Until then, `s` on a job the agent prepared hands it to the Simplify hand-off, and `f` says "not yet".
- **A job that starts from the top of its chain uses today's policy.** That covers a new job, or one sent back with `r`, even with earlier attempts. Before, a job queued before the agent existed kept its old chain (`simplify_auto → simplify → manual`) and never reached the agent.

## First real-model run (on a fake page, so no real site)
Opus 5.5 started on a job description and clicked "Apply now". It asked about every field at once, then filled the name, email, sponsorship ("Yes", from answers.yaml) and CV. It sent the 4 questions only you can answer to Needs input, including a field inside an embedded frame. It didn't click Next. 28 s, about 34k tokens.
