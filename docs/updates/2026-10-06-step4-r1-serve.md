# 2026-10-06 — Step 4 R1: `auto-app serve`

## What
The app runs by itself ([docs/step4-run.md](../step4-run.md) §1–§3, as built §11): **collect** in rounds, **judge each round's new jobs as one batch**, **pause**, repeat.

- **Round goals for collecting:** a source's round ends when **every search is caught up** (it reached postings already collected, or the end of its results), or at a **time cap** spread across its searches, or at optional volume caps. Its summary says "caught up" or "stopped by …". Also on `auto-app run` as `--time-limit 30m`, `--max-new N`, `--round-pages N`.
- **The loop:** collect (`auto-app run`) → one `filter run` batch on every job not judged yet → the pause **from the end of collecting** (30 min ± 20%). The next round also waits for the batch, so the gap adapts to the round. Rounds only run inside your window (08:00–23:00 by default). Sources can have their own cap, `every` (e.g. company sites every 6 h) or `enabled: false`.
- **Edge cases:**
  - **No usage left** → judging and collecting wait until the reset the error names (or retry every 15 min). One notice; it resumes by itself.
  - **A job failing 3 times** (while its filter works on others) → **unjudgeable**, skipped by `filter run`; `filter run --job N` gives it a fresh start.
  - **A broken filter** (won't load; a login, key or model error; or 3 different jobs failing with none working) → **notified at once, collecting stops** until `serve resume`, which judges the backlog first.
- **Notifications** (macOS): new recommendations ("ask Claude Code"), usage used up, a broken filter, a source needing a login.
- **Commands:** `serve run [--once]`, `serve status`, `serve pause [--until 2h | 09:00 | <date time>]`, `serve resume`, `serve install / remove` (launchd, KeepAlive). State in `data/serve.json`; round reports in `data/logs/serve-rounds.jsonl`; settings in `config/serve.yaml` (template `config/serve.example.yaml`).

**Fixed along the way:**
- Per-source goals weren't storable with the batch.
- YAML reads `off:` as false, so a source is now turned off with `enabled: false`.
- A search out of its time share now says "stopped by time_limit".
- **Stopping:** SIGTERM (launchd) and Ctrl-C now stop cleanly. A stop mid-collect used to hang, because the browser driver's tasks never finished; now, after 15 s, `serve` saves "not running" and exits. The browser closes with it, and nothing collected is lost.
