# Step 3 A1: the apply queue, applier chains, Simplify hand-off, `apply inbox` — 2026-10-04
**Step:** 3   **Status:** done. Tested offline. Usable on every platform through the hand-off; nothing is submitted by the app.

## What
- **Your files** (git-ignored; templates committed):
  - `profile/profile.yaml`, `profile/answers.yaml` and `profile/cv.pdf` (templates in `profile.example/`);
  - `config/apply.yaml` (template `config/apply.example.yaml`, the same as the defaults).
  - `auto-app apply profile` and `apply policy` check them. `apply profile` lists missing files, invalid entries, the CV and the common answers still missing. `apply policy` shows each platform's chain with ✓ built / … not built yet, and flags unknown appliers or platforms, chains not ending in `manual`, and LinkedIn Easy Apply with an automated applier.
- **Platform** from each job's apply link: `greenhouse`, `lever`, `ashby`, `workday`, `linkedin_easy_apply` (no employer link) or `other`.
- **Applier chains with fallback.** An applier that can't take the job, or isn't built yet, is skipped (`unsupported`). One that fails is retried once, then skipped. A hand-off parks the job for you. A chain that runs out leaves it `failed`. Every attempt is recorded with its outcome and reason.
- **Appliers built:**
  - **simplify:** opens the apply link in your Chrome, where Simplify autofills; you submit.
  - **manual:** opens the link and shows your CV in Finder.
  - greenhouse / lever / ashby / workday / generic are planned, and skipped for now.
- **`auto-app apply queue`** lists your want-to-apply jobs, each with its platform, chain and status. **`apply run`** (`-j N`) starts applications. **`apply list`** (`--status`) shows the history.
- **`auto-app apply inbox`**, with each tab's footer showing only its keys:
  - **Hand-offs:** `o` open, `a` applied (the job becomes `applied`), `c` couldn't (next applier), `l` later, `d` drop (the job becomes `not applied`);
  - **Failed:** `r` retry the chain, `m` apply by hand, `d` drop;
  - **Done:** `o` open the link.
  
  The detail pane shows the chain and every attempt.
- **Storage:** `applications` and `attempts` tables (migration `98559836bdfd`).

## As built (vs. the design)
- `apply run` is one-shot: it opens applications and moves each to its first working applier.
- The posting-still-open check and the pace apply to automated submission, so they come with A3 / A5.
- A failed application isn't reopened by `apply run`; you retry it in the inbox.
- The `questions` table comes with A2.

## How to use
```bash
cp -r profile.example profile && cp ~/path/to/cv.pdf profile/cv.pdf   # fill in profile/*.yaml
uv run auto-app apply profile
uv run auto-app apply queue
uv run auto-app apply run
uv run auto-app apply inbox
```
