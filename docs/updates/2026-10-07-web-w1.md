# Web frontend: design + W1, Jobs in your browser — 2026-10-07

**Design** ([docs/web-frontend.md](../web-frontend.md)):
- **What:** the full app in a browser (Jobs, Apply, Audit, Status) next to the TUI, which stays.
- **Stack:** FastAPI API + React / Vite / TypeScript.
- **Access:** this Mac only (127.0.0.1, a `Host` / `Origin` guard).
- **Same code:** the same as the TUI (`JobBrowser` / `Review`).
- **Never:** no submit endpoint, and nothing from `profile/` or `.env` is served.
- **Milestones:** W1 browse, W2 decide and label, W3 Apply and Status, W4 Audit.

**W1, as built:**
- `auto-app web [--port] [--open] [--build] [--dev] [--db]`;
- `src/auto_app/web/` (`app.py`: the API and the static app; `build.py`: npm build and dev server);
- `web/` (React app: `src/App.tsx`, `src/api.ts`, `src/styles.css`); `web/dist` and `node_modules` are
  git-ignored, and the app is built on first run;
- **The Jobs page:**
  - the TUI's tabs with counts;
  - narrowing: search, source, company, a filter's verdict, date posted;
  - a table and a detail pane (facts, link, every verdict with its reason, lookups and your label; postings;
    description);
  - keys `↑↓ / j k`, `[ ]`, `/`, `o`;
  - the view kept in the URL; a refresh every 30 s; light and dark; a narrow layout.
- **New dependencies:** `fastapi`, `uvicorn`.
- **Fixed while testing:** `salary` (an object) crashed the detail pane, so it's now sent as text, and an error
  boundary keeps one bad job from blanking the page.

**Tests:** `tests/test_web.py` (6):
- the API and its narrowing;
- the localhost guard;
- serving the build;
- a Playwright run of the built page (skipped without `web/dist`).

Checked by hand on `data/try.db`: all 130 jobs render.
