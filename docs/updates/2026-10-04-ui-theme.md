# Full-screen apps follow the system's light / dark mode — 2026-10-04
**Step:** 2 (apps)   **Status:** done. Detection checked live on macOS (light mode → `textual-light`).

## What
- `filter review` and `job browse` used Textual's default dark theme whatever the system's mode was.
- New setting `AUTO_APP_UI__THEME`, default **`auto`**: at start, and every 3 s while open, the app reads the system's mode and switches between `AUTO_APP_UI__LIGHT_THEME` (default `textual-light`) and `AUTO_APP_UI__DARK_THEME` (default `textual-dark`).
  - A theme picked with `ctrl+p` stays until the system's mode changes.
  - Any Textual theme name can be set instead of `auto` for a fixed theme. An unknown name stops the command with the list of themes.
- **How the mode is read:**
  - macOS: `defaults read -g AppleInterfaceStyle`;
  - Linux: `gsettings … color-scheme`;
  - Windows: the `AppsUseLightTheme` registry value;
  - if it can't be read, the theme is left as is.
